# Патрология — сайт курса

Сайт готов к размещению на GitHub Pages. Файлы презентаций (.pptx, .pdf) на сайт не входят: слайды показаны как картинки, тексты лекций читаются с экрана.

## Как выложить (≈10 минут)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите «+» → **New repository**. Название, например, `patrology`. Выберите **Public**, нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки `patrology-site` (файлы index.html, lecture-1.html и т. д. и папки `assets`, `slides`). Нажмите **Commit changes**.
   Если браузер не принимает папки, загрузите их по частям: сначала файлы, затем папку `slides`.
5. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Source: Deploy from a branch*, ветка **main**, папка **/ (root)**, нажмите **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/patrology/`.

## Как обновить

Откройте нужный файл в репозитории и загрузите новую версию через **Add file → Upload files** с тем же именем. Сайт обновится через минуту.

Новую лекцию проще всего добавить, прислав тексты и презентацию Claude: он пересоберёт сайт целиком.
